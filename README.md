I'm looking for a software engineering internship, and I build software that real people depend on. My main project runs the exam prep of a test-prep academy in Kazakhstan.

### [KD Academy](https://github.com/magz-code/kd-academy)

An exam-prep platform in production, built with TypeScript, Next.js, PostgreSQL and Prisma.

- **In use:** 43 student accounts and 3,691 saved answers in its first weeks.
- **Scoring:** paid exams weight each question by how hard it turned out to be, and published results never change.
- **Exams:** timers enforced on the server, per section with breaks, with no background jobs.
- **Tools for teachers:** upload a PDF, and the browser cuts it into questions and reads the answer key.
